# Third-party components

## RIFE ncnn Vulkan
Source: https://github.com/nihui/rife-ncnn-vulkan
License: MIT

The Android build uses the RIFE v4.6 network with ncnn's Vulkan backend.

## ncnn
Source: https://github.com/Tencent/ncnn
License: BSD-3-Clause (see the upstream ncnn repository for the complete license text).

FrameGen itself does not claim to be AMD FSR 3.1/FSR 4. The neural interpolation path is an independent implementation using the above open-source components.
